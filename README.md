# Masha CV Builder

## Live website

[Open Masha CV Builder](https://raleaalexia-cmyk.github.io/CV_making/)

A polished, responsive CV builder that runs in the browser. Create a CV, upload a profile photo, edit your experience and education, choose a font and accent color, and export a print-ready PDF.

## Run locally

Open `index.html` in a modern browser. No build tools or dependencies are required.

Your CV details and preferences are saved in your browser's local storage. Select **Export PDF** and choose **Save as PDF** in the print dialog to download your CV.

## Files

- `index.html` — page structure and CV builder interface
- `styles.css`, `customize.css`, `theme.css` — responsive layout, CV styles, and black-and-pink theme
- `app.js` — live preview, autosave, customization, and PDF print flow
